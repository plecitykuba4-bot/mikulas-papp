# Mikuláš Papp — osobní web

Návrh osobního webu full stack vývojáře Mikuláše Pappa.

- Vite + React 19 + TypeScript
- 3D: three.js přes React Three Fiber (notebook v hero, stůl v sekci Cesta, obálka v kontaktu)
- GSAP ScrollTrigger + Lenis

```bash
npm install
npm run dev
npm run build
```

Texty jsou v `src/content.ts`. E-mail se zapne doplněním `CONTACT_EMAIL`.
